# Architecture decisions

This directory contains durable “why” decisions. ADRs explain context, alternatives,
the decision, and consequences. They are not a second architecture handbook and
should be superseded rather than rewritten when a decision changes.

Each ADR records both `Decision date` and `Recorded` date. Existing decisions that
predate this directory use `Decision date: Predates ADR repository` and must not be
read as decisions made by the documentation migration.
